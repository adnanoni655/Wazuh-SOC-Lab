# Incident Response Report: Brute Force Attack Detection

## Executive Summary

This report documents the investigation of a simulated brute force attack detected by Wazuh in a home Security Operations Center (SOC) lab. Multiple failed SSH authentication attempts triggered security alerts, allowing the incident to be identified, analyzed, and documented.

---

## Incident Information

| Item | Value |
|------|-------|
| Incident Type | Brute Force Attack |
| Severity | Medium |
| Detection Tool | Wazuh SIEM |
| Endpoint | Windows 10 Home |
| Detection Method | Multiple Failed SSH Authentication Attempts |
| MITRE ATT&CK Technique | T1110 – Brute Force |

---

## Detection

Wazuh generated authentication failure alerts after repeated unsuccessful SSH login attempts against the Windows endpoint.

The alerts indicated:

- Multiple failed login attempts
- Repeated authentication failures
- Potential password guessing activity

---

## Investigation

The investigation included the following steps:

1. Reviewed authentication failure alerts in the Wazuh Dashboard.
2. Examined timestamps to identify repeated login attempts.
3. Confirmed the source of the SSH connections.
4. Verified that no successful login occurred.
5. Correlated the alerts with MITRE ATT&CK Technique **T1110 – Brute Force**.

---

## Impact Assessment

No unauthorized access was achieved during the simulation.

The activity was generated intentionally for testing purposes and successfully demonstrated Wazuh's ability to detect repeated authentication failures before an attacker could gain access.

---

## MITRE ATT&CK Mapping

| Technique ID | Technique | Tactic |
|--------------|-----------|--------|
| T1110 | Brute Force | Credential Access |

---

## Indicators of Compromise (IOCs)

The following indicators were observed during the investigation:

- Multiple failed SSH authentication attempts
- Repeated login failures from the same source
- Authentication Failure alerts generated by Wazuh
- No successful authentication events

---

## Response Actions

The following actions would be recommended in a production environment:

- Block the attacking IP address using a firewall.
- Enable Multi-Factor Authentication (MFA).
- Enforce strong password policies.
- Configure account lockout policies after repeated failed login attempts.
- Continue monitoring authentication logs for suspicious activity.
- Review additional endpoint logs for signs of compromise.

---

## Lessons Learned

This exercise demonstrated how Wazuh can rapidly detect brute force attacks through centralized log collection and authentication monitoring. The automatic MITRE ATT&CK mapping provided valuable context, enabling analysts to understand attacker behavior and respond more efficiently.

---

## Conclusion

The simulated brute force attack successfully validated Wazuh's detection capabilities. The platform generated timely alerts, correlated events with the MITRE ATT&CK framework, and provided clear visibility into authentication activity. This exercise demonstrates practical SOC analyst skills, including event monitoring, threat investigation, incident documentation, and security analysis.
