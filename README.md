\# Wazuh SOC Lab



\## Overview



This project demonstrates the design and implementation of an end-to-end Security Operations Center (SOC) lab using Wazuh SIEM.



The lab simulates how a SOC analyst monitors Windows endpoints, detects security events, investigates attacks, maps alerts to the MITRE ATT\&CK framework, performs vulnerability management, and documents incident response activities.



\---



\## Lab Environment



\### Operating Systems

\- Ubuntu Server 22.04

\- Windows 10 Home



\### Security Platform

\- Wazuh Manager

\- Wazuh Dashboard

\- Wazuh Indexer

\- Wazuh Agent



\---



\## Lab Objectives



\- Install Wazuh SIEM

\- Connect Windows Endpoint

\- Configure File Integrity Monitoring (FIM)

\- Detect Brute Force Login Attempts

\- Monitor Windows PowerShell Activity

\- Integrate Microsoft Defender

\- Perform Vulnerability Detection

\- Investigate MITRE ATT\&CK Techniques

\- Create an Incident Response Report
